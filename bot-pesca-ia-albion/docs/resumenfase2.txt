═══════════════════════════════════════════════════════════════════════════
 DECISIONES DE DISENO
═══════════════════════════════════════════════════════════════════════════

  Navegacion:
  - Se usa RIGHT-CLICK HOLD (no left-click, no WASD) para mover al personaje
  - pydirectinput en lugar de pyautogui para clicks (DirectInput, compatible con juego)
  - El minimapa es player-centered: el jugador siempre esta en el centro
  - get_water_direction() detecta la masa de agua mas cercana y retorna vector normalizado

  Deteccion de spots (descartado enfoque automatico):
  - HoughCircles detecta demasiados falsos positivos (arbustos, animales en movimiento)
  - Template matching sobre imagen Canny: no suficientemente robusto en movimiento
  - Mascara de agua 3D (SPOT_AGUA3D): mejora pero no elimina falsos positivos
  - DECISION FINAL: el usuario marca spots manualmente con F3 durante modo --explorar
  - Los spots se guardan como referencia de minimapa + coordenadas de lanzamiento

  Spots por minimapa:
  - Al marcar un spot (F3): se guarda crop 150x150 del centro del minimapa
  - En modo pesca: cv2.matchTemplate compara minimapa actual vs referencias guardadas
  - Similitud >= 0.65 = spot reconocido → pescar → cooldown 60s

═══════════════════════════════════════════════════════════════════════════
 FLUJO DE USO (FASE 2)
═══════════════════════════════════════════════════════════════════════════

  1. Calibrar minimapa:
       python calibrar_minimap.py
       (seleccionar region, verificar deteccion del jugador, calibrar agua)

  2. Explorar y grabar spots:
       python recorrer_spots.py --explorar --nombre willowfish_marsh
       Bot navega al agua y recorre la orilla automaticamente.
       Presionar F3 en cada spot visible → click sobre el spot → ENTER.
       F4 guarda waypoints/willowfish_marsh_spots.json

  3. Pescar:
       python recorrer_spots.py --nombre willowfish_marsh
       Bot recorre la orilla. Cuando el minimapa coincide con un spot
       grabado, para y lanza la linea. F4 para detener.

  4. Test sin clicks:
       python recorrer_spots.py --explorar --nombre willowfish_marsh --dry-run
